# OKP Rapekan - Landing Page

Landing page untuk organisasi kepemudaan **RAPEKAN** (Ranah Pemuda Kreatif Pakuwon). Didesain untuk menampilkan inisiatif sosial, pengelolaan lingkungan, dan produk kriya lokal dengan estetika modern, natural, dan premium.

## Tech Stack
- HTML5 Semantik
- CSS3 (Flexbox/Grid, CSS Variables)
- Vanilla JavaScript
- GSAP & ScrollTrigger (Animasi Scroll)
- Feather Icons

## Fitur Utama
- **Preloader Animasi:** Memberikan kesan premium saat memuat website.
- **Bento Grid Layout:** Menampilkan 4 pilar program dengan rapi.
- **Micro-interactions:** Hover effects, scroll animation, counter numbers.
- **Responsive & Mobile-First:** Tampilan optimal di semua perangkat.

## Cara Menjalankan
1. Ekstrak atau clone repository ini.
2. Buka file `index.html` langsung di browser, atau
3. Gunakan extension Live Server di VSCode.
